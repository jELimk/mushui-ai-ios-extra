# 沐水 AI 專用額外版（以 1.6.1 為基礎）

此專案獨立於正式沐水主線，不是 1.6.2；之後正式開發仍以原始 1.6.1 為基礎。已刪除人類帳號、好友、真人聊天、真人通話及伺服器依賴。

所有介面、字體、表情包與 AI 功能均隨 App 安裝。你只需在 App 設定自己的 AI API 網址、模型與金鑰，不必架設或重新 build 沐水伺服器。聊天與圖片／語音辨識直接傳給你選定的 API；Keychain 保存金鑰，本機原子檔案保存角色、聊天及記憶。

GitHub Actions 產生真正 iPhone ARM64 Mach-O App 並封裝 IPA。由於未提供 Apple 簽章憑證，IPA 名稱含 unsigned，需在 Windows 使用自己的 Apple 帳號簽章側載，不是點檔案就能直接安裝。安裝流程見 INSTALL_WINDOWS_IOS.md。

保留 AI 主動訊息／朋友圈與 AI 通話功能；iOS 暫停 App、鎖屏或關閉時，自主排程可能停止，不能保證持續背景 AI 訊息。沒有用無聲音訊假裝背景運行。App 可離線開啟並查看本機資料，呼叫 AI、辨識與生圖仍需網路。
